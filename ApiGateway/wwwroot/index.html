🧩 Unified Microservice Routing

Seamlessly routes incoming upstream requests to downsteam .NET 10 microservices using lightweight, file-based configuration profiles.

🛡️ Native Token Validation

Built-in JWT validation and OAuth2 authorization filters directly handled at the gateway edge layer before hits reach downstream microservices.

Program.cs 
            
// Add Ocelot configuration file
builder.Configuration.AddJsonFile("ocelot.json", optional: false, reloadOnChange: true);

// Inject Ocelot core services
builder.Services.AddOcelot();

var app = builder.Build();

// Use the Ocelot pipeline in .NET 10
await app.UseOcelot();
